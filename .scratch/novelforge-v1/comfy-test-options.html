ComfyUI test image

A prompt box and a Test button that draw one image with your saved ComfyUI choices. The picture below is a real Klein 9B image from today's run.

The same in all three
  • It sits at the bottom of the ComfyUI part of Settings, after the notes, and shows only when the Image provider is Local.
  • It uses the saved Settings, like the model lists do, so save before testing.
  • While drawing, the button reads "Drawing…". A failure shows ComfyUI's reason in the same place as the image.
  • The image goes in no Save, and the next test replaces it.

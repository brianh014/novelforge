## Comments

The user asked for this directly, so no options report was needed. The user didn't say where the text goes. It shows one description at a time, for the chosen theme, rather than nine at once.

World creation, Enhance, the PC and the cover all take the theme from the same value as Pick for me.

Later the user chose to rename Sci Fi Fantasy to Space Opera, keeping its magic in the description. Urban Fantasy, Post-Apocalyptic, Horror and Noir were added. Superhero was offered and left out unless the user asks.

# 18: Portraits and NPC references

**What to build:** The PC and NPCs get portraits, which appear in the Journal and help keep them consistent in Scene Images.

**Blocked by:** 10, 16, 17

**Status:** ready-for-agent

- [ ] An NPC portrait is generated the first time they appear in a Scene, not when merely mentioned
- [ ] Each NPC stores appearance text used in image prompts
- [ ] Portraits appear beside NPCs in the Journal
- [ ] Portraits of visible NPCs are passed as references where the model supports it
- [ ] Portraits count toward the session image count and respect the images toggle

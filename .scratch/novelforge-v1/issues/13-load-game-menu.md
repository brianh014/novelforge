# 13: Load Game menu

**What to build:** A player can manage their Saves from the Load Game menu: load, duplicate, delete, import and export. Old Saves keep working after updates.

**Blocked by:** 09

**Status:** ready-for-agent

- [ ] The menu lists Saves and can load one
- [ ] A player can duplicate a Save
- [ ] Delete requires confirmation
- [ ] A player can export a Save as one file
- [ ] Import validates the file and rejects anything that isn't a valid Save without affecting existing Saves
- [ ] Old Saves are migrated when opened, with a test covering an older format

# 15: World creation wizard

**What to build:** A player can create a world through the wizard, and the Narrator generates its World Bible, Plot Threads and World Overview. The player reviews only the World Overview.

**Blocked by:** 09

**Status:** ready-for-agent

- [ ] The wizard offers every theme in the spec, plus a custom theme
- [ ] A player can write a World Brief or use “Pick for me”
- [ ] A player can turn the Starting Hook on or off, write one, or use “Pick for me”
- [ ] A player can choose any Art Style in the spec or describe their own
- [ ] Generation produces Lore Entries with several keywords each, `world_rules` and Plot Threads
- [ ] A spoiler-free World Overview is shown, with accept or regenerate
- [ ] Marker tests prove the player-facing wizard never reveals the World Bible or Plot Threads
- [ ] A generation failure can be retried without losing the player's input

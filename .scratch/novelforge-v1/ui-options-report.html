Ticket 08 / awaiting your choice

NovelForge UI options

Three visual directions, each mocked up on the game screen, a wizard step, the Journal and the inventory at desktop and phone widths, plus four Chat styles. Pick one direction or mix parts. UI code starts after you choose.

The story text here is hand-written. No real-model Turn has been run yet, so every line of narration is a stand-in written by hand, in the same shape the game stores. Real Narrator prose may run longer or read differently. Review the fit again after the real-model run from ticket 07.

Scene Images and portraits are drawn stand-ins as well, because image generation isn't built yet. All mockups are throwaway: none of this HTML or CSS goes into the app.

How to choose

Every part has a label. Reply with labels, for example “A1 with B3 and B4, Chat style 2”, or just “B”. In a mix, the game screen's type and palette carry over to the other parts unless you say otherwise. On a phone, desktop mockups shrink to fit, so read those on a larger screen.

Chat styles

The spec lists Chat style as a Settings option and leaves the options open. These four show the same Messages, so only the presentation changes. Each one works with any direction. A1 uses Script, B1 uses Prose and C1 uses Bubbles. Tell me which ones to ship and which is the default.

The sample story

Tamsin Vey, a relief lamp-keeper, reaches a dark lighthouse on the tidal islands of the Reach. The world is original to this report. It runs for three Turns, so six Messages, and every mockup above shows this same moment. Theme: Fantasy. Art style: Luminous Fluid Watercolor.

The shape matches the code today: a Narrator reply holds narration and state_operations, each Message has an id, role and text, and the Snapshot holds inventory, status and pcKnown.
